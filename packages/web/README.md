# @mnestia/web

The slide deck preview application built with TanStack Router and React.

## Overview

This package provides the UI for previewing Mnestia slide decks. It's a prebuilt React application that works with the `@mnestia/vite-plugin` to render slides dynamically.

## Features

- **TanStack Router** - File-based routing for slide navigation
- **Lazy loading** - Slides load on-demand via React.lazy()
- **Theme support** - Dynamic theme loading
- **Keyboard navigation** - Arrow keys, space, vim bindings
- **Responsive** - Works on different screen sizes

## Development

```bash
bun install

# Dev server (runs on port 3000)
bun run dev

# Type check
bun run typecheck

# Build
bun run build
```

## Architecture

The web app consumes virtual modules generated by the vite-plugin:

```typescript
// From virtual:mnestia/deck
import { deckConfig } from "virtual:mnestia/deck";

// From virtual:mnestia/slides  
import { slides } from "virtual:mnestia/slides";

// slides is an array of lazy-loaded components
slides[0].component // React.LazyExoticComponent
```

## Components

- `DeckProvider` - Provides deck state and theme
- `SlideViewer` - Renders current slide with layout
- `NavigationControls` - Slide navigation UI
- `SlideLoading` - Loading placeholder for lazy slides
