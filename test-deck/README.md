# mnestia Starter Template

Welcome to your new slide deck project!

## Getting Started

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```

## Project Structure

```
├── slides/
│   └── index.md          # Your main slides
├── public/               # Static assets
├── package.json
└── README.md
```

## Writing Slides

Slides are written in Markdown with YAML frontmatter:

```markdown
---
title: My Slide
---

# Hello World

Your content here...
```
